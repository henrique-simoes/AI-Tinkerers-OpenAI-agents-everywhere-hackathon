## The two named prizes

### 🏆 Best Use of CopilotKit — purple AirPods Max per team member
Load-bearing means: the agent's interface **is** CopilotKit — real in-app actions,
generative UI, shared state with the agent. Cosmetic means: a chat bubble dropped into a
page. Judges distinguish these easily.
→ [copilotkit-and-ag-ui.md](copilotkit-and-ag-ui.md)

### 🏆 Best Use of Ambiguous AI — one NVIDIA DGX Spark for the team
Load-bearing means: the agent has a **real identity in the workspace**, is reachable the
way a colleague is (email, chat, @mention, task assignment), and produces artifacts humans
continue working on in the same apps. Cosmetic means: one API call to create a doc.
→ [ambiguous-ai.md](ambiguous-ai.md)

**These two are also the best thematic fit for the challenge**, because both answer
"which untapped context?" with a concrete place people already work.

## Choosing

Pick **two** sponsors to go deep on. A typical strong stack:

```
CopilotKit (interface)  +  Ambiguous AI (the context/workspace)
   ├─ OpenAI Agents SDK          the reasoning loop
   ├─ Exa                        retrieval when it needs the open web
   ├─ Trigger.dev                anything that outlives an HTTP request
   └─ OpenRouter                 failover when a provider rate-limits mid-demo
```

Auth0 Token Vault enters whenever the agent must act on a user's third-party accounts —
it converts an idea that the public-repo rule would kill into one that is legitimate.

## Credits worth noting

- OpenAI credits are the headline prize at all three placements.
- **Exa credits are attached to all three placements** — the organizers clearly want Exa used.
- Ambiguous AI is free for teams up to 5 with 1,000 AI actions/month ✅ — enough for a hackathon.
- Check at the venue: sponsors frequently hand out additional credits on the day.

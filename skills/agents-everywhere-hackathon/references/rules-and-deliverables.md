## The challenge

> Most AI agents still operate inside a separate chat window. This build day starts from a
> different premise: the most useful agents will be the ones that appear inside the tools,
> channels, devices and environments where people already do their work and their daily
> lives. **Build a working agent that acts in an untapped context.**

Suggested surfaces — **"only examples, not separate categories or tracks"**:

- **At work** — Slack, Teams, email, documents, calendars, ticketing, support, real-time collaboration.
- **In your pocket** — messaging apps, mobile devices, notifications, quick async interactions.
- **On the web** — browsers and software where an agent can search, browse, transact, or act.
- **Physical** — voice, computer vision, wearables, robotics, other real-world interfaces.

## The five mandatory deliverables

Submitted before the event closes. **All five, or the entry is not qualified.**

1. **Title** — a clear name for the project.
2. **Written description** — what was built, who it is for, and **why the chosen context matters**.
3. **Public GitHub repository** — working code that can be reviewed, reused, and learned from.
4. **Two-minute video** — an objective demonstration of the project working.
5. **Social media post** — a public post about the project, mentioning the event sponsors.

> "Build something that can be shown in practice. A clear, working demo is worth more than
> an ambitious idea that has not been executed."
